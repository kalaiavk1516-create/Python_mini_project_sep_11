# Python_mini_project_sep_11

📊 Customer Support Ticket Analyser
🔹 Project Type
Python Mini Project – Data Cleaning & Analysis

🔹 Overview
This project is a Customer Support Ticket Analyser built in Python. It helps organize, clean, and analyze customer support tickets to extract meaningful insights. The tool simulates a real-world support system where tickets are logged, cleaned, and categorized for better decision-making.

🔹 Features
✅ Ticket Entry & Expansion – Add new tickets dynamically with validation for priority levels.

✅ Text Cleaning – Normalize issue descriptions (lowercasing, punctuation removal, word corrections).

✅ Keyword Insights – Count tickets containing specific keywords like poor, good, slow, excellent.

✅ Priority Analysis – Summarize ticket counts by High, Medium, and Low priority.

✅ Longest Issue Detection – Identify the ticket with the longest issue description.

✅ Unique Word Extraction – Generate a sorted list of unique words used in all tickets.
